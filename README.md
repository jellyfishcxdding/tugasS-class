#  Tugas S-Class: Gamified To-Do List

We're creating a To-Do List application designed to boost productivity through a built-in reward and streak system. 

*Note: This repository contains the Phase 1 Prototype. The full application is currently under active development and will be published soon.*

##  Key Features (Prototype Scope)
- **Task Management:** Track and complete daily to-do items.
- **Streak System:** Encourages consistency by recording consecutive days of task completion.
- **Reward Mechanism:** Gamifies the experience to keep users motivated.
